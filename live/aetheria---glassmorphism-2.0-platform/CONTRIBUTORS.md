# دليل المساهمين وقائمة المساهمة (Contributors & Contribution Guide)

أهلاً بك في دليل المساهمين لمشروع **Aetheria - Glassmorphism 2.0 Platform**. يسعدنا انضمامك وتلقي مساهماتك المتميزة لتطوير وتنسيق هذا المشروع المفتوح المصدر.

---

## 1. كيف يمكنك المساهمة؟ (How to Contribute)

يمكنك المساهمة في هذا المشروع بعدة طرق مختلفة:

1. **الإبلاغ عن المشاكل (Reporting Issues):**
   - إذا وجدت خطأً برمجياً (Bug) أو مشكلة في التأثيرات البصرية للزجاج، قم بفتح **Issue** جديد مع توضيح خطوات إعادة إنتاج المشكلة ونوع المتصفح المستخدَم.

2. **تطوير ميزات جديدة (Adding Features):**
   - تصميم مؤشرات بصرية جديدة أو تحسين أداء تأثيرات الزجاج الثلاثي الأبعاد.
   - تحسين استجابة الواجهة للأجهزة الذكية والشاشات ذات الأبعاد المختلفة.

3. **تحسين التوثيق (Improving Documentation):**
   - تصحيح النصوص أو إضافة توضيحات باللغة العربية أو الإنجليزية لتطوير ملفات الشرح.

---

## 2. خطوات تقديم الطلبات (Pull Request Process)

اتبع الخطوات التالية لتقديم تعديلاتك:

1. **نسخ المستودع (Fork the Repository):**
   قم بإنشاء نسخة خاصة بك من المشروع على حسابك في GitHub.

2. **إنشاء فرع جديد (Create a Feature Branch):**
   ```bash
   git checkout -b feature/my-new-glass-feature
   ```

3. **تثبيت الحزم وتشغيل المشروع (Install & Run):**
   ```bash
   npm install
   npm run dev
   ```

4. **التحقق من جودة الكود (Linting & Verification):**
   تأكد من عدم وجود أخطاء في TypeScript أو التنسيق قبل إرسال التعديل:
   ```bash
   npm run build
   ```

5. **إرسال طلب الدمج (Submit Pull Request):**
   قم بإرسال Pull Request يشرح التعديلات التي قمت بها والأهداف منها بوضوح.

---

## 3. إرشادات وقواعد البرمجة (Coding Guidelines)

- **TypeScript:** استخدم أنماط قوية ومتطابقة في `src/types.ts` وتجنب استخدام `any`.
- **Styling:** اعتمد على Tailwind CSS والأنماط المخصصة في `src/index.css` دون إضافة ملفات CSS عشوائية.
- **Icons:** استخدم أيقونات حزمة `lucide-react` فقط.
- **Performance:** حافظ على سلاسة التمرير والتأثيرات بنسبة 60-120 إطاراً في الثانية (FPS).
