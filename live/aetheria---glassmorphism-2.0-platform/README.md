## 🛠️ التشغيل والبدء السريع (Quick Start)

1. **تثبيت التبعيات (Install Dependencies):**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```

3. **بناء المشروع للإنتاج (Build Production Bundle):**
   ```bash
   npm run build
   ```

## 💻 التقنيات المستخدمة (Tech Stack)

- **لغة البرمجة:** TypeScript & HTML5 / CSS3
- **إطار الواجهة:** React 19 + Vite 6
- **التنسيق والواجهات:** Tailwind CSS v4 + Custom Refraction Engine
- **الرسوم البيانية:** Recharts
- **الأيقونات:** Lucide React
