# 🩸 معرض الرعب — Dark Gallery

معرض فني مرعب تفاعلي بُني بالكامل باستخدام **HTML + CSS + JavaScript + GSAP** (لا صور خارجية). كل لوحة فنية مرسومة بالكود عبر **SVG** — جماجم، أشباح، عيون دامية، خفافيش ليلية، وحوش، قمر دموي، وقلوب ميتة نابضة.

> "ابواب تُطرق بلا أيدي، أصوات بلا أفواه، لوحات تنظر إليك."

---

## ✨ المزايا

### 🎨 محتوى فني
- **14 لوحة فنية** مولّدة بالكامل عبر SVG (لا تعتمد على أي صور خارجية).
- **7 فئات رعب**: جماجم، أشباح، عيون، خفافيش، وحوش، قمر، قلوب.
- لوحة بطل رئيسية: الجمجمة الملكية المتوّجة بعيون متوهجة.
- 4 لوحات مميزة مع قصص وأوصاف.

### 🕷️ تفاعلات مرعبة
- **شاشة دخول (Intro)** مع عين راقبة وتحذير — اضغط ESC أو زر الدخول للمتابعة.
- **عين تتبع الماوس** متوهجة تلاحق مؤشرك في كل مكان.
- **عيون اللوحات** تتحرك نحو موقع الماوس (تتبع بصري).
- **قطرات دم** نازلة من أعلى الصفحة بشكل متكرر.
- **انفجار دموي** عند النقر على أي لوحة في المعرض.
- **Lightbox** لعرض اللوحات بحجم أكبر مع وصف القصة، يدعم التنقل بلوحة المفاتيح.
- **بحث + فلترة** فورية داخل المعرض حسب الفئة والنص.

### 🔊 صوت محيط مرعب
- صوت ambient مرعب مولّد عبر **Web Audio API** (نغمتان منخفضتان مستمرتان).
- زر تشغيل/إيقاف الصوت في الهيدر.
- يبدأ تلقائياً عند دخول المعرض (قد يتطلب تفاعل المستخدم حسب سياسة المتصفح).

### 🌐 تجربة المستخدم
- **ثنائي اللغة (عربي/إنجليزي)** كامل مع تبديل فوري و RTL/LTR.
- **وضع داكن/فاتح** — الافتراضي داكن بروح الرعب.
- **متجاوب بالكامل** (موبايل/تابلت/سطح المكتب).
- شريط تقدّم للتمرير + زر العودة للأعلى.
- عدّادات متحركة + كتابة متحركة (typing effect).
- يحترم `prefers-reduced-motion` لإيقاف الأنميشن لمن يفضّل ذلك.
- إمكانية الوصول (aria-labels, focus management, skip link).

### 🎬 مكتبات
- **GSAP** (عبر CDN) للحركات المتقدمة عند الدخول والفلترة وفتح Lightbox.
- باقي التأثيرات مكتوبة بـ CSS و Vanilla JS بدون مكتبات إضافية.

## 🚀 التشغيل

ببساطة افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً محلياً:

```bash
# خيار 1: Python
python -m http.server 8000

# خيار 2: Node
npx serve

# ثم افتح: http://localhost:8000
```

> ملاحظة: GSAP يُحمّل من CDN، لذا يُفضّل وجود اتصال بالإنترنت عند أول تشغيل (أو حمّل gsap.min.js محلياً وعدّل المسار في index.html).

## 🛠️ كيف أُنشئت اللوحات؟

كل لوحة معرّفة كـ JavaScript object داخل `paintings` في `script.js`:

```js
skull1: {
  cat: "skulls",
  ar: "الجمجمة الضاحكة",
  en: "The Laughing Skull",
  descAr: "تبتسم دائماً...",
  descEn: "Always smiling...",
  svg: `<svg viewBox="0 0 200 240">...</svg>`
}
```

المعرض يُبنى ديناميكياً عبر `buildGallery()` ويُحقن SVG داخل كل عنصر. لإضافة لوحة جديدة، فقط أضف إدخالاً جديداً للـ object.

## ⚠️ تحذير

هذا المعرض لأغراض الفن والترفيه. قد يحتوي على عناصر مزعجة بصرياً (عيون دامية، جماجم، أصوات مرعبة). إن كنت حساساً لمحتوى الرعب أو تعاني من صرع ضوئي، فعّل `prefers-reduced-motion` في نظامك أو تجنّب تشغيل الصوت.
