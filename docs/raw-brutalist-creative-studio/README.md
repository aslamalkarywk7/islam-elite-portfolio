A cutting-edge, high-impact **RAW Neo-Brutalist** creative studio portfolio web application built with React 19, TypeScript, and Tailwind CSS v4. Designed with deliberate hyper-bold typography, hard 5px strokes, zero gradients, electric lime accents, and an interactive studio monitor mockup mode.

---

## ⚡ Project Overview

RAW Creative Studio showcases digital craftsmanship for experimental web engineering, brand identity, and physical installations. The platform rejects corporate pastel templates and soft rounded SaaS trends in favor of an uncompromising visual identity that commands immediate user attention.

---

## 🚀 Key Features

1. **Hyper-Bold Display Typography**:
   - Ultra-heavy display scales featuring Syne, Montserrat, and Space Mono typography paired with `-webkit-text-stroke` outline effects.
   - Interactive Headline Cycler and type scale adjustments.

2. **Unconventional Asymmetrical Vertical Grid**:
   - Staggered layout blocks with 5px solid hard strokes (`#000000`), hard drop shadows with zero blur, and overlapping badge stamps.

3. **High-Impact Monochromatic + Electric Lime Palette**:
   - Pure black (`#000000`), pure white (`#FFFFFF`), and sharp electric lime accents (`#CCFF00`).
   - Zero gradients guarantee WCAG AA 21:1 ultra-high contrast readability.

4. **Interactive Poster Studio Engine**:
   - In-browser real-time Neo-Brutalist poster generator with live rotation, stamp customization, color theme switching, and instant HTML/Tailwind spec code export.

5. **Web Audio Synthesizer (Tactile Feedback)**:
   - Built-in Web Audio API synth generating heavy pops, glitch beeps, and mechanical click feedback on interactive buttons.

6. **Photorealistic 8K Studio Display Mockup Mode**:
   - Dual viewing modes: Direct **RAW UI** mode and a photorealistic **8K Studio Monitor Mockup** mode complete with customizable ambient lighting, CRT scanlines, and glare simulation.

7. **Commission Proposal Calculator & Terminal**:
   - Real-time deliverable selection estimator with instant project cost calculation, turnaround timelines, and text receipt transmission.

8. **Interactive Case Study Inspector**:
   - Detailed modal popups featuring project challenges, solutions, measured impact, RGB shift toggles, and tech stack specifications.

## 🛠️ Technologies Used & Programming Languages

### Programming Languages
- **TypeScript (v5.8)**: Full static typing across components, project metrics, proposal states, and audio synth engines.
- **HTML5 & CSS3**: Native CSS Custom Properties, Web Audio API, and custom keyframe marquee animations.

### Frameworks & Libraries
- **React 19 (`react`, `react-dom`)**: Modern functional component architecture with hooks.
- **Vite (v6.2)**: Blazing-fast Next-Gen frontend build engine.
- **Tailwind CSS v4 (`@tailwindcss/vite`)**: Utility-first styling framework with custom hard stroke and hard shadow extensions.
- **Lucide React (`lucide-react`)**: High-contrast icon system.
- **Motion (`motion`)**: High-performance animation primitives.
- **Express (v4.21)**: Server-side environment setup for Node.js production container deployment.

## ⚖️ Pros & Cons Analysis

### ✅ Advantages (Pros)
- **High Visual Impact**: Stand out immediately from thousands of generic, pastel-colored SaaS templates.
- **Ultra-Fast Performance**: Zero heavy 3D asset overhead; crisp CSS box models ensure rapid page renders (<0.15s).
- **Extreme Contrast & Accessibility**: Pure `#000000` on `#CCFF00` or `#FFFFFF` achieves maximum legibility (21:1 contrast ratio).
- **Responsive Architecture**: Fully adapted across mobile touch targets and wide-screen desktop displays.
- **Modular Component Design**: Clean separation of concerns across data models, audio synth utilities, and UI components.

### ⚠️ Trade-offs / Considerations (Cons)
- **Aesthetic Specificity**: Neo-Brutalism is intentionally aggressive and may not suit conservative corporate or healthcare brands.
- **Intense Visual Density**: Large headline typography and raw layout overlaps require deliberate spatial budgeting.
- **Audio Autoplay Rules**: Modern browsers require initial user interaction before enabling Web Audio API sounds.

## 💻 Installation & Quickstart

### Prerequisites
- Node.js (v18.0 or higher)
- npm or bun

### Step 1: Clone & Install Dependencies
```bash
# Clone the repository
git clone https://github.com/your-username/raw-creative-studio.git
cd raw-creative-studio

# Install dependencies
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Step 3: Build for Production
```bash
npm run build
npm start
```

## 📐 Design System Rules

1. **5px Hard Strokes**: Every container and card MUST have a `5px solid #000000` (or `#FFFFFF`) border.
2. **Zero Gradients**: No smooth color transitions or soft drop shadows.
3. **Hard-Edged Drop Shadows**: Use `box-shadow: 8px 8px 0px #000000` with 0px blur radius.
4. **Electric Lime Accent**: Accent highlights must strictly utilize `#CCFF00`.
