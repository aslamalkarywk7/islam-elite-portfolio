# الوثيقة الشاملة لنظام Oman Luxury Dash

## 1. معلومات المشروع الكاملة (Project Information)
مشروع **Oman Luxury Dash** هو لوحة تحكم إدارية (Admin Dashboard) فائقة الفخامة، تم تصميمها خصيصاً لمنصة **Nashar Studio** لإدارة المشاريع لتطوير الفلل في الموج (Al-Mouj Villa Development). 

**الهدف الرئيسي:** 
تقديم نظام رقمي يعتمد على "الرفاهية الهادئة" (Quiet Luxury)، يتيح لمديري المشاريع تتبع الأداء المالي، الانحرافات المتعلقة بالتكلفة، نسبة الهدر في المواد الاستهلاكية الفاخرة مثل الرخام الإيطالي، وإعطاء تقييم ذكي (AI).

**أهم المقاييس المعتمدة:**
- **إدارة القيمة المكتسبة (EVM - Earned Value Management):** الأساس الرياضي للنظام.
- **Wastage Tracking:** تتبع هدر المواد الفاخرة وارتباطها بالتكلفة الفعلية (AC).

---

## 2. دليل التشغيل (Operating Guide)

لتشغيل خادم التطوير على البيئة المحلية وضمان أداء النظام بشكله الصحيح، اتبع الخطوات التالية:

### المتطلبات المسبقة:
- بيئة عمل `Node.js` الإصدار 20+ أو 22+.
- مدير الحزم `npm`.

### خطوات التشغيل:
1. قم بفتح نافذة الأوامر (Terminal) والتأكد من تواجدك في المجلد الرئيسي للمشروع.
2. تنزيل التبعيات البرمجية:
   ```bash
   npm install
   npm run build
   ```
3. تشغيل الخادم المحلي (Development Server):
   ```bash
   npm run dev
   ```
4. افتح المتصفح وتوجه إلى الرابط المخصص:
   `http://localhost:3000`

### دليل استخدام النظام:
- **إدخال البيانات:** من القائمة الجانبية يتم إدخال القيم الحالية (BAC, EV, PV, AC) و(طول وهدر الرخام بالمتر المربع).
- **منع الأخطاء الواردة:** يمنع النظام الحفظ في حال تجاوزت التكلفة المهدرة التكلفة الإجمالية، أو إذا طغت مساحة الهدر على المساحة المشتراة، لضمان دقة الرسوم.
- **تنبيهات النظام:** راقب المؤشر الأحمر العائم (Luxury Alert) الذي سيعمل تلقائياً عند تجاوز مؤشرات الصرف (Cost Variance) الحد المسموح.

## 3. خرائط الملفات (Architecture Map)

تمثيل شجري لهندسة النظام لأهم المسارات والملفات المكونة للتطبيق:

```text
src/
├── app/
│   ├── globals.css          # تنسيقات Tailwind والألوان الأساسية
│   ├── layout.tsx           # المكون الجذري والتغليف بالخطوط الفاخرة
│   ├── page.tsx             # الصفحة الرئيسية لإدارة البيانات والمخرجات
│   └── api/metrics/route.ts # مسار API للتواصل مع الخادم لمعالجة الأرقام
├── components/
│   ├── CustomCursor.tsx     # مكون المؤشر المتفاعل ذو اللون الذهبي
│   ├── Dashboard.tsx        # مكون لوحة التحكم العارضة للمخططات والبطاقات
│   ├── DataInputForm.tsx    # نموذج الإدخال مع التحقق وحفظ حالة البيانات
│   ├── InputForm.tsx        # مكون فرعي لنموذج الإدخال
│   └── PortfolioVisuals.tsx # مكون الرسومات البيانية Recharts
└── lib/
    ├── aiAnalysis.ts        # وحدة التقييم الذكي للنصوص واستخراج الرؤى
    ├── mathEngine.ts        # المحرك الرياضي وخوارزميات (EVM)
    ├── watermark.ts         # دوال التشفير والعلامة المائية الأولية
    └── WatermarkSecurity.ts # نظام الأمان والحماية المتقدم
```

## 4. وظائف المكونات والأنظمة (Core Functions & Features)

يقوم كل ملف ومكون في المشروع بوظيفة دقيقة لضمان سلاسة العمليات:

### 4.1 وظائف مكونات الواجهة المائية (`/components`)
- **`Dashboard.tsx` (لوحة العرض):** 
  - **الوظيفة:** يعتبر القلب النابض للعرض. يستقبل البيانات المحسوبة (Metrics) ويعرض مؤشرات الأداء (CPI, SPI) وبطاقات الاستثمار.
  - **المتغيرات المحورية:** يُمرر له بيانات المشروع وتكلفة الإنجاز المقدرة (EAC) ليقوم بتحديث الواجهة دون إعادة تحميل الصفحة (Real-time).
- **`DataInputForm.tsx` (نموذج الإدخال الذكي):**
  - **الوظيفة:** استلام المُدخلات من المستخدم، والمطابقة الرياضية (Validation) الفورية لمنع أي مستخدم من إدخال قيم متعارضة هندسياً.
  - **المتغيرات المحورية:** يدير حالة النموذج (State) ويعرض راية التنبيه (System Error Banner) في أسفل الصفحة عند الرصد لتوجيه المستخدم فوراً.
- **`PortfolioVisuals.tsx` (الرسومات البيانية):**
  - **الوظيفة:** تحويل الـ 10 متغيرات الأساسية والمالية إلى أعمدة ومسارات بصرية دقيقة تعكس الموقف الفعلي الزمني والمادي بكل وضوح عبر Recharts التي تعطي طابعاً تحليلياً دقيقاً (Terminal-Style).
- **`CustomCursor.tsx` (المؤشر المتحرك الفاخر):**
  - **الوظيفة:** إلغاء مؤشر النظام الافتراضي وتعويضه بمؤشر يتفاعل مع حركات الماوس، ويمتلك تأثير الزنبرك (Spring) ودوائر التموج (Ripple) لتعزيز الرفاهية الهادئة.

### 4.2 وظائف المحركات والمنطق الداخلي (`/lib`)
- **`mathEngine.ts` (المحرك المالي EVM):**
  - **الوظيفة:** يفصل عمليات الحساب المعقدة تماماً عن واجهة المستخدم. يقوم بحساب تباين التكلفة (CV) وتباين الجدول الزمني (SV) ونسبة الهدر المالي والمساحي للرخام بدقة مطلقة لمنع القسمة على الصفر وغيرها.
- **`aiAnalysis.ts` (التحليل الذكي):**
  - **الوظيفة:** تحليل نواتج المحرك المالي، فإذا كان مثلاً `CPI < 1` يقوم بإنتاج رسالة نصية (Warning) لتوجيه المدير بتقليل الهدر أو ضبط النفقات بصيغة إنجليزية مفهومة.
- **`WatermarkSecurity.ts` (نظام الأمان المتقدم):**
  - **الوظيفة:** آلية حماية معقدة غير مرئية توثق جلسة الزائر وتخفي معلومات النظام بخوارزمية دمج (XOR Pattern) و`SESSION_TAG` لمنع السرقات البرمجية أو نقل الشفرات لجهات غير مصرح لها.

### 4.3 الأنظمة التفاعلية المدمجة (Interactive UI Functions)
- **تأثير مسح الرادار (Radar Sweep):** شريط يُعطي المستثمر الانطباع بأن النظام يقوم بمعالجة عميقة للبيانات عند الإدخال.
- **واجهات تحليل تقاطعية (Analytical Crosshairs):** تقديم قراءة دقيقة للإحداثيات الاستثمارية عند المرور على الرسم البياني، مما يسهل رصد الخلل.
- **الظهور المتدرج (Staggered Fade-Up Reveal):** عناصر واجهة تدخل بشكل متسلسل وأنيق عند تحميل الصفحة لزيادة الشعور بالفخامة.
- **التغذية اللمسية الظاهرية (Haptic feedback):** أزرار ونماذج تتفاعل بشكل ناعم وعميق يعكس تصميم הـ "Quiet Luxury" المتبنى في المشروع.
